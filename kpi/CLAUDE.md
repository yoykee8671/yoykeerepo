# KPI (공헌이익) — 작업 지침

우프컴퍼니 공헌이익 KPI + 보너스 정산 도구. 전체 맥락은 `kpi-dev-summary.md`, 설계 근거는 `DESIGN.md`, 월간 갱신 절차는 `MONTHLY-UPDATE.md`.

## 연동 맵 — 같은 데이터 2번 긁지 않기

- 원천 데이터 조회는 **clobe MCP 한 창구**(user 스코프, 어느 폴더에서나 사용 가능). 조회 전 get_scraping_status로 수집 기준일 확인.
- 이 폴더의 담당은 "파생 집계": `costs-monthly-clobe.json`(1~N월 원가), `autofill-raw.json`(채널별 실입금), `kpi-autofill.js`(자동채움, generate-autofill.py가 생성 — 수기수정 금지).
- `~/AI_CFO`(일일 재무 브리핑 폴더)가 `costs-monthly-clobe.json`·`autofill-raw.json`·`kpi-dev-summary.md`를 `~/AI_CFO/원장/kpi/` 심볼릭 링크로 소비한다.
  → **이 3개 파일의 이름·위치를 바꾸면 AI_CFO가 조용히 깨진다.** 바꿀 땐 링크와 `~/AI_CFO/연결목록.md` 경로를 같이 고칠 것.
- 채널→유닛 매핑 SSOT는 `generate-autofill.py`의 CHANNEL_MAP. AI_CFO `분류규칙.csv`는 그 사본(+사업부 칸). 매핑을 수정하면 AI_CFO 재이관이 필요하다고 사용자에게 알릴 것.
- 대용량 원천 조회(전표 완주, 은행 수확)는 sonnet 서브에이전트로 위임해 메인 컨텍스트를 아낀다. 서브에이전트는 원본을 반드시 JSONL로 남기고, 메인에서 재집계로 재현 검증한다.

## 확정 정책 (2026-11-05 대표 확정)

- **월간 갱신**: 매월 1일 로컬 트리거로 실행. 절차는 `MONTHLY-UPDATE.md`.
- **결산 재반영**: 과거 월 숫자가 바뀌면 집계 파일은 자동 갱신하고 월별 변경폭을 보고한다 (사전 승인 불필요 — 원본 JSONL이 보존돼 되돌리기 가능).
- **신규 거래처**: 분류 규칙에 없는 키는 금액과 무관하게 **전부 사용자에게 분류를 질문**한다. 임의 배정 금지. 답을 받기 전까지는 미분류/other로 집계하고 질문 목록을 보고서에 남긴다.
- **git**: main 직접 커밋 금지. `feat/kpi-*` 브랜치에 로컬 커밋까지만 자동으로 하고, push·PR·배포는 사용자 확인 후.
- **kpi.html 입력 데이터**: 브라우저 localStorage(파일 경로 origin 단위) 저장. 자동채움 재생성 후 적용은 사용자가 각 월에서 ⚡ 버튼. 폴더 이동 전에는 설정 탭 JSON 내보내기 백업 필수.

## 숫자 검증 원칙

- 커서 페이징은 hasNext=false까지 **완주**. 부분 집계면 반드시 그렇다고 명시.
- 서브에이전트 집계는 메인에서 원본 JSONL 재집계로 재현 검증하고, 직접 본 값 몇 개를 스팟체크한다.
- 교차검증 차이가 수 % 이내면 숫자 오류보다 기준 차이(카드매입 포함 여부, 결산 전/후, 발생/현금주의)부터 의심한다. 차액을 맞추려고 데이터를 임의로 고치지 않는다.
- 클로브 전표·은행 데이터는 마지막 수집 시점 기준(실시간 아님). 회계법인 엑셀 장부는 결산 전 자료일 수 있다.
